# Vocabulary — frequency list (Traditional Chinese / Taiwan)

Ordered by frequency. Work top-down. This is a **seed** covering the
highest-frequency core (roughly the top 100); expand it from a corpus source
(see `sources.md`) until you cover the top ~1,000, then ~2,000.

Traditional characters throughout. Where a form differs in Simplified, it is
noted only in `notes.md` — keep this file Traditional-only.
