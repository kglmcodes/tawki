# Grammar / sentence patterns — frequency order

Ranked by how often the structure shows up in everyday Mandarin, not by
textbook order. Traditional Chinese (Taiwan). See `../README.md` for the method.

## Pattern list

### 1. Basic word order (SVO)
- **Does:** subject-verb-object; the default frame.
- **Structure:** Subject + Verb + Object
- **Examples:**
  - 我喜歡咖啡。 (I like coffee.)
  - 他吃蘋果。 (He eats an apple.)
- **Status:** [ ] learning  [ ] solid

### 2. 是 (shì) — "to be" / identification
- **Does:** equates two things.
- **Structure:** A + 是 + B
- **Examples:**
  - 我是學生。 (I am a student.)
  - 他是台灣人。 (He is Taiwanese.)
- **Status:** [ ] learning  [ ] solid

### 3. 的 (de) — possession / modification
- **Does:** links a modifier to a noun.
- **Structure:** Owner + 的 + Noun
- **Examples:**
  - 我的書。 (my book)
  - 很好的人。 (a very good person)
- **Status:** [ ] learning  [ ] solid

### 4. 這 / 那 + measure word
- **Does:** this/that + noun, needs a measure word.
- **Structure:** 這/那 + 量詞 + Noun
- **Examples:**
  - 這個人。 (this person)
  - 那本書。 (that book)
- **Status:** [ ] learning  [ ] solid

### 5. 不 vs 沒 (negation)
- **Does:** 不 negates present/habitual/will; 沒 negates 有 and past/completed.
- **Structure:** 不 + Verb/Adj | 沒(有) + Verb
- **Examples:**
  - 我不去。 (I'm not going.)
  - 我沒去。 (I didn't go.)
- **Status:** [ ] learning  [ ] solid

### 6. Question forms
- **Does:** 嗎 (yes/no), A-not-A, or a question word left in place.
- **Structure:** S + V + O + 嗎? | V-不-V? | 什麼/誰/哪裡/怎麼/幾…
- **Examples:**
  - 你好嗎? (How are you?)
  - 你去不去? (Are you going?)
  - 你要什麼? (What do you want?)
- **Status:** [ ] learning  [ ] solid

### 7. 了 (le) — completion / change
- **Does:** marks a completed action or a new situation.
- **Structure:** Verb + 了 (+ Object)
- **Examples:**
  - 我吃了。 (I ate.)
  - 下雨了。 (It started raining.)
- **Status:** [ ] learning  [ ] solid

### 8. 過 (guò) — past experience
- **Does:** "have ever done" something.
- **Structure:** Verb + 過
- **Examples:**
  - 我去過日本。 (I've been to Japan.)
- **Status:** [ ] learning  [ ] solid

### 9. Location and progress: 在 / 正在
- **Does:** 在 marks location; 正在 (or 在) marks an action in progress.
- **Structure:** 在 + Place | (正)在 + Verb
- **Examples:**
  - 我在家。 (I'm at home.)
  - 我正在吃飯。 (I'm eating right now.)
- **Status:** [ ] learning  [ ] solid

### 10. 把 (bǎ) — disposal / object fronting
- **Does:** moves the object before the verb, often with a result.
- **Structure:** 把 + Object + Verb (+ result)
- **Examples:**
  - 把書放在桌上。 (Put the book on the table.)
- **Status:** [ ] learning  [ ] solid

### 11. 被 (bèi) — passive
- **Does:** marks the doer in a passive sentence.
- **Structure:** Object + 被 (+ doer) + Verb
- **Examples:**
  - 我的錢被偷了。 (My money was stolen.)
- **Status:** [ ] learning  [ ] solid

### 12. 因為…所以 / 雖然…但是 / 如果…就
- **Does:** the core connector pairs.
- **Examples:**
  - 因為下雨，所以我沒去。 (Because it rained, I didn't go.)
  - 雖然很貴，但是我買了。 (Although it's expensive, I bought it.)
  - 如果你來，我就去。 (If you come, I'll go.)
- **Status:** [ ] learning  [ ] solid

### 13. Modality: 想 / 要 / 會 / 可以 / 應該
- **Does:** want / intend / can-will / may / should, before the verb.
- **Examples:**
  - 我想去。 (I want to go.)
  - 我會說中文。 (I can speak Chinese.)
  - 你應該休息。 (You should rest.)
- **Status:** [ ] learning  [ ] solid

### 14. 比 (bǐ) — comparison
- **Does:** A is more <adj> than B.
- **Structure:** A + 比 + B + Adj
- **Examples:**
  - 他比我高。 (He is taller than me.)
- **Status:** [ ] learning  [ ] solid

### 15. 太…了 (tài … le) — "too …"
- **Does:** excessive degree.
- **Examples:**
  - 太貴了。 (Too expensive.)
  - 太好了。 (Great! / Too good.)
- **Status:** [ ] learning  [ ] solid
