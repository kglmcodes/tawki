# Notes

Observations, gotchas, mnemonics, confusions worth remembering. Traditional
Chinese (Taiwan) usage.

## Simplified vs Traditional (forms used here)

| Traditional | Simplified | Meaning |
|---|---|---|
| 這 | 这 | this |
| 說 | 说 | to say |
| 會 | 会 | can / will |
| 們 | 们 | plural marker |
| 個 | 个 | measure word |
| 來 | 来 | to come |
| 什麼 | 什么 | what |
| 因為 / 所以 | 因为 / 所以 | because / therefore |

Taiwan-specific vs mainland vocabulary (to watch as it comes up), e.g. 網路
(TW "internet") vs 网络, 計程車 (TW taxi) vs 出租车.
